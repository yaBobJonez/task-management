# Програма управління задачами

Цей репозиторій містить експериментальний проєкт студентів групи М-F2-26-1-ПІ на тему
«Вплив характеристик набору автоматизованих перевірок на тривалість автоматизованого
складання програмних проєктів CI/CD-конвеєрами» з дисципліни «Методологія прикладних
досліджень у сфері інженерії програмного забезпечення» — застосунок для управління
задачами за підходом Kanban-дошки. Програма написана мовою C++ із використанням
фреймворку Qt 6; тести створюються на GTest.
